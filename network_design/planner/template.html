How the optimizer works

PQC (ML-KEM / ML-DSA) protects every link. A substation counts as QKD-protected only if every hop to a control center has QKD, with at most the chosen number of trusted relays. Score = load protected (MW × route km) + weight × traffic watched on QKD fiber. The page runs greedy path selection plus swap local search with restarts. For the presets at default settings it is checked against the exact integer program (SciPy HiGHS) from the notebooks.

Attack tests: a tap is caught only on a QKD link; trusted-node loss exposes keys relayed through it; one cut fiber can isolate substations unless a backup route exists.
